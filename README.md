# 还款方案工作台

贷款服务人员使用的还款试算工作台，包含两个工作区：

1. **提前还款对比**：对**同一笔提前还款**，分别生成
   **缩短期限（月供不变）** 与 **降低月供（期限不变）** 两种还款计划，
   逐期展示本金、利息、剩余余额，并对比两种方案在期数、月供、总利息上的差异。
2. **宽限与延期模拟**：配置若干**不重叠的宽限区间**（只还利息 / 完全暂停且利息资本化 /
   暂停后一次性补缴），把延期事件与提前还款放在明确的日内顺序中重新生成计划，
   单独列示正常利息、延期利息、资本化金额与新增期数，并提供原方案 / 延期方案差额视图。

- 后端：Spring Boot 3 + Java 21，全部金额使用 `BigDecimal`（2 位小数，HALF_UP）
- 数据库：PostgreSQL 16（保存模拟合同、计算记录、延期政策与模拟记录的政策快照）
- 前端：Angular 18（独立组件）
- **仅使用模拟合同，不连接任何真实放贷接口**

## 目录结构

```
backend/    Spring Boot 计算与持久化服务（端口 8080）
frontend/   Angular 工作台（开发端口 4200，/api 代理到 8080）
scripts/    本地环境（JDK / Maven / PostgreSQL）与启动脚本
```

## 计算规则（固定月度规则）

- 月利率 = 年利率 / 12（保留 12 位小数）；每期利息 = 期初剩余本金 × 月利率（四舍五入到分）
- **等额本息**：月供 `M = P·r·(1+r)^n / ((1+r)^n − 1)`，每月还款额固定
- **等额本金**：每月偿还本金 `P / n` 固定，月供逐月递减
- **缩短期限**：保持原月供水平（等额本息保持月供金额、等额本金保持月还本金），逐月模拟至结清
- **降低月供**：期限不变，按提前还款后本金重新计算计划
- 提前还款金额直接冲减本金；手续费为一次性成本，计入总成本但不冲减本金
- **末期自动结清**：末期本金 = 当期期初剩余本金，尾期后余额恰好为 0，不出现负余额

## 宽限与延期模拟规则

- 宽限区间为剩余计划内的**期次闭区间**（如第 2~4 期），可配置多个；
  **相邻区间允许**（前一区间结束期的下一期即为后一区间起始期），**重叠区间拒绝**（前端与后端均校验）
- 区间内三种处理方式：
  - **只还利息**：每期只付当期利息，本金不变，期限相应顺延
  - **暂停并资本化**：当期不还款，利息计入本金，**下一期计息基数增加**，期限顺延
  - **暂停后一次性补缴**：当期不还款，应还本息挂账（挂账本金按影子余额计算，
    保证补缴本金不超过区间开始时的实际余额），区间结束后的第一期一次性补缴，期限不变
- 还款水平按原合同确定后全程不变（等额本息保持月供、等额本金保持月还本金），
  期限自动顺延，**尾期精确结清**（末期后余额恰好为 0）
- 提前还款在指定期次的还款日冲减本金（当期利息仍在期初余额上计提）；
  金额传 0 表示不提前还款
- **日内顺序（同一期次还款日，固定不变）**：
  区间退出一次性补缴 → 利息资本化 / 挂账 → 提前还款 → 当期还款；
  当期利息在期初余额（含此前资本化）上计提，不受当日事件影响
- 结果单独列示：**正常利息**（非区间期次计提）、**延期利息**（区间期次计提）、
  **资本化金额**、**新增期数**（延期方案期数 − 原方案期数，两方案适用同一笔提前还款）
- **政策快照**：延期政策（一组宽限区间）可保存、可修改；每次模拟把当时使用的区间
  作为政策快照随记录保存，**政策修改后历史记录仍按原快照可复现**
  （`POST /api/deferral/simulations/{id}/replay` 按快照重算并比对存档结果）

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/contracts` | 模拟合同列表 |
| POST | `/api/contracts` | 新建模拟合同 |
| POST | `/api/calculations/compare` | 生成两种方案对比并保存记录 |
| GET | `/api/calculations` | 历史计算记录 |
| GET | `/api/calculations/{id}` | 单条计算记录（含完整结果） |
| GET | `/api/deferral/policies` | 延期政策列表 |
| POST | `/api/deferral/policies` | 新建延期政策（一组宽限区间） |
| PUT | `/api/deferral/policies/{id}` | 修改延期政策（不影响历史记录快照） |
| POST | `/api/deferral/simulations` | 延期模拟（政策或内联区间二选一）并保存记录 |
| GET | `/api/deferral/simulations` | 历史延期模拟记录 |
| GET | `/api/deferral/simulations/{id}` | 单条模拟记录（含政策快照与完整结果） |
| POST | `/api/deferral/simulations/{id}/replay` | 按记录的政策快照重算，验证可复现 |

利率在 API 与数据库中均为小数形式（`0.049` 表示 4.9%），前端负责 % 换算。

## 示例核对（与单元测试一致）

两种还款方式共用参数：剩余本金 1,000,000.00 元，年利率 4.9%，剩余 240 期，
提前还款 200,000.00 元，手续费 500.00 元（提前还款后本金 800,000.00 元）。

### 等额本息（月供固定）

| 指标 | 不提前还款（基准） | 缩短期限 | 降低月供 |
|---|---|---|---|
| 月供 | 6,544.44 | 6,544.44（不变） | 5,235.55 |
| 期数 | 240 | 170 | 240 |
| 总利息 | 570,665.67 | 310,467.06 | 456,532.99 |

逐期抽查（基准计划）：第 1 期利息 4,083.33、本金 2,461.11、余额 997,538.89；
末期（第 240 期）还款 6,544.51，结清后余额 0.00。缩短期限方案末期（第 170 期）
还款 4,456.70，结清后余额 0.00。

### 等额本金（月还本金固定）

| 指标 | 不提前还款（基准） | 缩短期限 | 降低月供 |
|---|---|---|---|
| 月还本金 | 4,166.67 | 4,166.67（不变） | 3,333.33 |
| 首月/末月月供 | 8,250.00 / 4,182.88 | 7,433.34 / 4,183.04 | 6,600.00 / 3,347.74 |
| 期数 | 240 | 192 | 240 |
| 总利息 | 492,041.29 | 315,233.07 | 393,633.72 |

逐期抽查（基准计划）：第 1 期本金 4,166.67、利息 4,083.33、月供 8,250.00；
末期本金兜底 4,165.87（= 1,000,000 − 239 × 4,166.67），结清后余额 0.00。

结论（两种还款方式一致）：**缩短期限总利息明显更低，但月供压力不变；
降低月供保持期限、减轻月供压力，但总利息更高。** 本例中缩短期限比降低月供
节省利息：等额本息 146,065.93 元，等额本金 78,400.65 元。

> 上表数值由 `AmortizationServiceTest` 实际计算输出，测试同时断言：
> 各期本金合计 = 贷款本金、末期后余额为 0、全程无负余额、每期月供 = 本金 + 利息。

### 宽限与延期模拟示例（与 `DeferralSimulationServiceTest` 一致）

剩余本金 100,000.00 元，年利率 12%（月利率 0.01），剩余 12 期，等额本息（月供 8,884.88）：

| 场景 | 关键结果 |
|---|---|
| 第 3~5 期只还利息 | 区间内本金保持 84,151.39 不变、每期只付息 841.51；新增 3 期至 15 期；延期利息 2,524.53 |
| 第 3~4 期资本化 | 第 3 期利息 841.51 计入本金 → 84,992.90，第 4 期计息基数增加（利息 849.93）；资本化合计 1,691.44；顺延至 15 期，尾期 1,887.07 精确结清 |
| 第 3~4 期暂停后补缴 + 第 5 期提前还款 10,000 | 第 5 期（宽限结束日）事件顺序固定为：补缴 17,769.76 → 提前还款 10,000 → 当期还款 8,884.88；期数与原方案一致（11 期），利息差 257.00 |

> 测试同时断言：相邻区间可处理而重叠区间被拒、逐期余额结转自洽、
> 本金守恒（计划内本金 + 提前还款 = 原剩余本金 + 资本化金额）、
> 现金守恒（总还款 = 原剩余本金 + 总利息）、同样输入重复模拟结果完全一致；
> `DeferralServiceTest`（H2 内存库）断言政策修改后历史记录仍按原快照复现。

## 本地运行

```bash
# 1. 启动 PostgreSQL（用户态 PostgreSQL 16，无需 root；首次自动初始化并建库）
scripts/start-postgres.sh

# 2. 启动后端（端口 8080；已打 jar 则直接运行 jar，否则 mvn spring-boot:run）
scripts/start-backend.sh

# 3. 启动前端开发服务器（另开终端，端口 4200，/api 代理到 8080）
scripts/start-frontend.sh
# 打开 http://localhost:4200
```

前端生产构建后（`cd frontend && npx ng build`）将 `dist/frontend/browser`
复制到 `backend/src/main/resources/static`，即可由后端单端口 8080 同时托管页面与 API。

运行测试：

```bash
cd backend && ../tools/maven/bin/mvn test
```

> 本环境未预装 Java / PostgreSQL，`tools/` 下为免 root 的
> Temurin JDK 21、Maven 3.9 与 PostgreSQL 16（aarch64）运行时。
